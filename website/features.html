Built-In Core Suite

Four tightly integrated applications running on zero-latency Firebase Cloud infrastructure.

App 01 — Smartboard Desktop

Genatis Board / Canvas

Interactive flat panel and desktop app designed for active classroom instruction and real-time attendance logging.

  • ✓ Digital Interactive Whiteboard with sticky notes & shape tools
  • ✓ PDF Annotator with History Blob Exports
  • ✓ 1-Tap Attendance Logger with virtualization for large classes
  • ✓ Live Period & Timetable Hero Display

App 02 — Administrator Cloud Portal

Genatis Command

Full cloud telemetry dashboard for Principals, IT Directors, and Coordinators to manage school data without IT overhead.

  • ✓ 1-Click CSV Roster Import with automatic path sanitization
  • ✓ Live Daily Attendance Telemetry Hub (Submitted vs Pending classes)
  • ✓ 1-Tap Emergency SOS Broadcast & Lockdown Trigger
  • ✓ Substitute Teacher Delegation with PIN authentication
  • ✓ School Bulletins & Circulars Publishing Board
Included in Core

App 03 — Teacher Mobile App

Genatis Staff

iOS & Android mobile app giving teachers full mobility around campus with complete offline resilience.

  • ✓ On-the-Go Attendance for assigned classes
  • ✓ Direct Teacher-to-Parent messaging with read receipts
  • ✓ Lesson Log & Session Summary entry
  • ✓ Offline persistence (Zustand + NetInfo guards)
Included in Core

Dedicated parent app providing complete transparency into their child's school day.
